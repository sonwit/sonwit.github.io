Dette gjelder de private hjemmeprosjektene på denne siden, inkludert appen hjemmeserver-backup-app. Appene brukes bare av eieren selv og tilbys ikke til andre.

hjemmeserver-backup-app (Google Drive)

  • Hva appen får tilgang til: bare filer appen selv har laget i eierens Google Drive (tilgangen drive.file). Den kan ikke se, lese eller endre andre filer.
  • Hva data brukes til: å lagre og hente kryptert backup av eierens egen hjemmeserver. Dataene krypteres på serveren før de lastes opp.
  • Deling: ingen data deles med, selges til eller overføres til andre. Ingen data brukes til reklame, analyse eller trening av modeller.
  • Lagring og sletting: backupen ligger i eierens egen Google Drive og kan slettes der når som helst. Tilgangen kan trekkes tilbake under Google-kontoens innstillinger for tredjepartstilgang.

Bruk og overføring av informasjon mottatt fra Google API-er følger Google API Services User Data Policy, inkludert kravene om begrenset bruk (Limited Use).

Fugleramme

Fugleramme tar lydopptak i eierens egen hage for å gjenkjenne fuglearter. Opptakene behandles lokalt på hjemmeserveren, slettes automatisk etter noen uker og deles ikke.
